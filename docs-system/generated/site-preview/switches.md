# switches

`switches([first[, last]])`



## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `first` | no | `the` | first switch index. If `nil` or omitted, the first available switch is used. |
| `last` | no | `the` | last switch index. If `nil` or omitted, the last available switch is used. |

## Returns

None.

## Availability

- Since: `2.6`
- Radio support: `all`
