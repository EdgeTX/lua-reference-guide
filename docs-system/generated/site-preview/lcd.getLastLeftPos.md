# lcd.getLastLeftPos

`lcd.getLastLeftPos()`

Returns the leftmost x position from previous drawtext or drawNumber output

## Parameters

None.

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `number` | `integer` | x position |

## Availability

- Since: `2.2.0`
- Radio support: `bw-lcd`

## Notes

- Only available on Taranis

`radio/src/lua/api_stdlcd.cpp`
