# model.resetTimer

`model.resetTimer(timer)`

Reset model timer to a startup value

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `timer` | yes | `integer` | timer index (0 for Timer 1) |

## Returns

None.
