# getRotEncSpeed

`getRotEncSpeed()`

Return rotary encoder current speed

## Parameters

None.

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `-` | `integer` | in list: ROTENC_LOWSPEED, ROTENC_MIDSPEED, ROTENC_HIGHSPEED returns ROTENC_LOWSPEED on radio without rotary encoder |

## Availability

- Since: `2.3.10`
- Radio support: `all`

`radio/src/lua/api_general.cpp`
