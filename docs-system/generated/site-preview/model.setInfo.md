# model.setInfo

`model.setInfo(value)`

Set the current Model information

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `value` | yes | `unknown` | model information data, see model.getInfo() |

## Returns

None.

## Availability

- Since: `2.0.6`
- Radio support: `all`

## Notes

- If a parameter is missing from the value, then
that parameter remains unchanged.
