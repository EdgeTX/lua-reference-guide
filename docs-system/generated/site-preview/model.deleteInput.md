# model.deleteInput

`model.deleteInput(input, line)`

Delete line from specified input

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `input` | yes | `integer` | input number (use 0 for Input1) |
| `line` | yes | `integer` | input line (use 0 for first line) |

## Returns

None.

## Availability

- Since: `2.0.0`
- Radio support: `all`
