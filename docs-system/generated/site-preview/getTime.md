# getTime

`getTime()`

Return the time since the radio was started in multiple of 10ms

## Parameters

None.

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `-` | `integer` | Number of 10ms ticks since the radio was started Example: run time: 12.54 seconds, return value: 1254 |

## Availability

- Since: `2.0.0`
- Radio support: `all`
