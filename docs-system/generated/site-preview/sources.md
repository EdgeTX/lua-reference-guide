# sources

`sources([first[, last]])`



## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `first` | no | `the` | first source index. If `nil` or omitted, the first available source is used. |
| `last` | no | `the` | last soure index. If `nil` or omitted, the last available source is used. |

## Returns

None.

## Availability

- Since: `2.6`
- Radio support: `all`
