# dir

`dir(directory)`

Return an iterator listing all the files and directories name in a directory

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `directory` | yes | `string` | Working directory |

## Returns

None.

## Availability

- Since: `2.5.0`
- Radio support: `all`
