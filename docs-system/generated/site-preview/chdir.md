# chdir

`chdir(directory)`

Change the working directory

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `directory` | yes | `string` | New working directory |

## Returns

None.

## Availability

- Since: `2.3.0`
- Radio support: `all`
