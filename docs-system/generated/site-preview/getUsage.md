# getUsage

`getUsage()`

Get percent of already used Lua instructions in current script execution cycle.

## Parameters

None.

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `usage` | `integer` | a value from 0 to 100 (percent) |

## Availability

- Since: `2.2.1`
- Radio support: `all`
