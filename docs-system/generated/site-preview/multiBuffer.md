# multiBuffer

`multiBuffer(address[,value])`

This function reads/writes the Multi protocol buffer to interact with a protocol.

## Parameters

| Name | Req | Type | Description |
| --- | --- | --- | --- |
| `address` | yes | `unknown` | to read/write in the buffer @param (optional): value to write in the buffer |

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `-` | `buffer` | value (number) |

## Availability

- Since: `2.3.2`
- Radio support: `all`
