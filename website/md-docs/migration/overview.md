# Migration Plan

The detailed migration plan lives in the repository root at `MIGRATION-PLAN.md`.

This MkDocs copy is a short navigation placeholder while the new site structure is being introduced.

## Key decisions

- upstream EdgeTX source is the owner of API truth
- first published output from the new pipeline is EdgeTX 2.12
- GitBook is replaced by MkDocs Material
- richer descriptions and examples live in overlays, not in generated output
- LuaLS definitions are generated from the same extracted API model as Markdown docs
