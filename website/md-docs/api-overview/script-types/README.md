# Script Types

| Script Type | Description |
| --- | --- |
| [One-Time Scripts](one-time-scripts.md) | Scripts launched on demand for tools, wizards, and other short-lived tasks that run until they finish or are closed. |
| [Telemetry Scripts](telemetry-scripts.md) | Background-capable screen scripts for radios with B&W displays, typically used to present custom telemetry pages. |
| [Widget Scripts](widget-scripts.md) | Persistent widget-based scripts for color LCD radios that extend main views and can render in widget zones or full-screen mode. |
| [Function Scripts](function-scripts.md) | Special Function helpers that run in response to configured switch states and are typically used for automation or announcements. |
| [Mixes Scripts](mixes-scripts.md) | Periodic processing scripts that transform model inputs into outputs for non-critical custom mixing logic. |
