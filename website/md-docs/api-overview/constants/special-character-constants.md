# Special Character Constants

| Constant name | Meaning |
| --- | --- |
| `CHAR_RIGHT` | Right arrow symbol |
| `CHAR_LEFT` | Left arrow symbol |
| `CHAR_UP` | Up arrow symbol |
| `CHAR_DOWN` | Down arrow symbol |
| `CHAR_DELTA` | Delta/change symbol |
| `CHAR_STICK` | Stick input category symbol |
| `CHAR_POT` | Potentiometer category symbol |
| `CHAR_SLIDER` | Slider category symbol |
| `CHAR_SWITCH` | Switch category symbol |
| `CHAR_TRIM` | Trim category symbol |
| `CHAR_INPUT` | Input category symbol |
| `CHAR_FUNCTION` | Function/source category symbol |
| `CHAR_CYC` | Cyclic / heli source category symbol |
| `CHAR_TRAINER` | Trainer source category symbol |
| `CHAR_CHANNEL` | Channel/output category symbol |
| `CHAR_TELEMETRY` | Telemetry category symbol |
| `CHAR_LUA` | Lua source/category symbol |
