# Logical Switch Function Constants

| Constant name | Meaning |
| --- | --- |
| `LS_FUNC_NONE` | No function |
| `LS_FUNC_VEQUAL` | `a = x` |
| `LS_FUNC_VALMOSTEQUAL` | `a ~ x` |
| `LS_FUNC_VPOS` | `a > x` |
| `LS_FUNC_VNEG` | `a < x` |
| `LS_FUNC_RANGE` | Value within range |
| `LS_FUNC_APOS` | `a > |x|` |
| `LS_FUNC_ANEG` | `a < |x|` |
| `LS_FUNC_AND` | `AND` |
| `LS_FUNC_OR` | `OR` |
| `LS_FUNC_XOR` | `XOR` |
| `LS_FUNC_EDGE` | Edge |
| `LS_FUNC_EQUAL` | `a = b` |
| `LS_FUNC_GREATER` | `a > b` |
| `LS_FUNC_LESS` | `a < b` |
| `LS_FUNC_DIFFEGREATER` | `∆ ≥ x` |
| `LS_FUNC_ADIFFEGREATER` | `|∆| ≥ x` |
| `LS_FUNC_TIMER` | Timer |
| `LS_FUNC_STICKY` | Sticky |
