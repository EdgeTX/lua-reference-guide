# Key Event Constants

## `EVT_...` constants

| Constant name | Meaning |
| --- | --- |
| `EVT_ENTER_FIRST` | ENTER key pressed |
| `EVT_ENTER_BREAK` | ENTER key released |
| `EVT_ENTER_LONG` | ENTER long press |
| `EVT_ENTER_REPT` | ENTER repeat while held |
| `EVT_MENU_FIRST` | MENU key pressed |
| `EVT_MENU_BREAK` | MENU key released |
| `EVT_MENU_LONG` | MENU long press |
| `EVT_MENU_REPT` | MENU repeat while held |
| `EVT_TELEM_FIRST` | TELE key pressed |
| `EVT_TELEM_BREAK` | TELE key released |
| `EVT_TELEM_LONG` | TELE long press |
| `EVT_TELEM_REPT` | TELE repeat while held |
| `EVT_MODEL_FIRST` | MODEL key pressed |
| `EVT_MODEL_BREAK` | MODEL key released |
| `EVT_MODEL_LONG` | MODEL long press |
| `EVT_MODEL_REPT` | MODEL repeat while held |
| `EVT_SYS_FIRST` | SYS key pressed |
| `EVT_SYS_BREAK` | SYS key released |
| `EVT_SYS_LONG` | SYS long press |
| `EVT_SYS_REPT` | SYS repeat while held |
| `EVT_UP_FIRST` | UP key pressed |
| `EVT_UP_BREAK` | UP key released |
| `EVT_UP_LONG` | UP long press |
| `EVT_UP_REPT` | UP repeat while held |
| `EVT_DOWN_FIRST` | DOWN key pressed |
| `EVT_DOWN_BREAK` | DOWN key released |
| `EVT_DOWN_LONG` | DOWN long press |
| `EVT_DOWN_REPT` | DOWN repeat while held |
| `EVT_LEFT_FIRST` | LEFT key pressed |
| `EVT_LEFT_BREAK` | LEFT key released |
| `EVT_LEFT_LONG` | LEFT long press |
| `EVT_LEFT_REPT` | LEFT repeat while held |
| `EVT_RIGHT_FIRST` | RIGHT key pressed |
| `EVT_RIGHT_BREAK` | RIGHT key released |
| `EVT_RIGHT_LONG` | RIGHT long press |
| `EVT_RIGHT_REPT` | RIGHT repeat while held |
| `EVT_PAGEUP_FIRST` | PAGE UP key pressed |
| `EVT_PAGEUP_BREAK` | PAGE UP key released |
| `EVT_PAGEUP_LONG` | PAGE UP long press |
| `EVT_PAGEUP_REPT` | PAGE UP repeat while held |
| `EVT_PAGEDN_FIRST` | PAGE DOWN key pressed |
| `EVT_PAGEDN_BREAK` | PAGE DOWN key released |
| `EVT_PAGEDN_LONG` | PAGE DOWN long/alternate page action |
| `EVT_PAGEDN_REPT` | PAGE DOWN repeat while held |
| `EVT_PAGE_FIRST` | PAGE key pressed on radios with a combined page key |
| `EVT_PAGE_BREAK` | PAGE key released on radios with a combined page key |
| `EVT_PAGE_LONG` | PAGE long press on radios with a combined page key |
| `EVT_PAGE_REPT` | PAGE repeat on radios with a combined page key |
| `EVT_PLUS_FIRST` | PLUS key pressed |
| `EVT_PLUS_BREAK` | PLUS key released |
| `EVT_PLUS_LONG` | PLUS long press |
| `EVT_PLUS_REPT` | PLUS repeat while held |
| `EVT_MINUS_FIRST` | MINUS key pressed |
| `EVT_MINUS_BREAK` | MINUS key released |
| `EVT_MINUS_LONG` | MINUS long press |
| `EVT_MINUS_REPT` | MINUS repeat while held |
| `EVT_SHIFT_FIRST` | SHIFT key pressed |
| `EVT_SHIFT_BREAK` | SHIFT key released |
| `EVT_SHIFT_LONG` | SHIFT long press |
| `EVT_SHIFT_REPT` | SHIFT repeat while held |
| `EVT_ROT_LEFT` | Rotary encoder rotated left |
| `EVT_ROT_RIGHT` | Rotary encoder rotated right |
| `EVT_EXIT_BREAK` | EXIT key released |

## `EVT_VIRTUAL_...` constants

| Constant name | Meaning |
| --- | --- |
| `EVT_VIRTUAL_PREV` | Previous field/navigation action |
| `EVT_VIRTUAL_PREV_REPT` | Previous field/navigation repeat |
| `EVT_VIRTUAL_NEXT` | Next field/navigation action |
| `EVT_VIRTUAL_NEXT_REPT` | Next field/navigation repeat |
| `EVT_VIRTUAL_DEC` | Decrease current value |
| `EVT_VIRTUAL_DEC_REPT` | Decrease current value repeatedly |
| `EVT_VIRTUAL_INC` | Increase current value |
| `EVT_VIRTUAL_INC_REPT` | Increase current value repeatedly |
| `EVT_VIRTUAL_PREV_PAGE` | Previous page action |
| `EVT_VIRTUAL_NEXT_PAGE` | Next page action |
| `EVT_VIRTUAL_MENU` | Open menu action |
| `EVT_VIRTUAL_MENU_LONG` | Long menu action |
| `EVT_VIRTUAL_ENTER` | Enter/confirm action |
| `EVT_VIRTUAL_ENTER_LONG` | Long enter/confirm action |
| `EVT_VIRTUAL_EXIT` | Exit/back action |
