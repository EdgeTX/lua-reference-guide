# Special Function Constants

| Constant name | Meaning |
| --- | --- |
| `FUNC_OVERRIDE_CHANNEL` | Override channel output |
| `FUNC_TRAINER` | Trainer mode action |
| `FUNC_INSTANT_TRIM` | Instant trim |
| `FUNC_RESET` | Reset selected value or state |
| `FUNC_SET_TIMER` | Set timer value |
| `FUNC_ADJUST_GVAR` | Adjust global variable |
| `FUNC_VOLUME` | Set volume source |
| `FUNC_SET_FAILSAFE` | Set failsafe |
| `FUNC_RANGECHECK` | Start range check |
| `FUNC_BIND` | Start bind mode |
| `FUNC_PLAY_SOUND` | Play sound |
| `FUNC_PLAY_TRACK` | Play audio track |
| `FUNC_PLAY_VALUE` | Play spoken value |
| `FUNC_PLAY_SCRIPT` | Play Lua script/function |
| `FUNC_BACKGND_MUSIC` | Background music |
| `FUNC_BACKGND_MUSIC_PAUSE` | Pause background music |
| `FUNC_VARIO` | Enable vario |
| `FUNC_HAPTIC` | Haptic feedback |
| `FUNC_LOGS` | Start logging |
| `FUNC_BACKLIGHT` | Backlight control |
| `FUNC_SCREENSHOT` | Take screenshot |
| `FUNC_RACING_MODE` | Racing mode |
| `FUNC_SET_SCREEN` | Change screen |
| `FUNC_DISABLE_AUDIO_AMP` | Disable audio amplifier |
| `FUNC_RGB_LED` | RGB LED control |
| `FUNC_TEST` | Test function |
